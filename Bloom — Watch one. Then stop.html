03 — Your data

Does my data leak? No.

Bloom can't send anything off your phone, and you can check that yourself.

InternetNo permission requested, so Android won't let Bloom connect.
What it readsInstagram's screen structure, only to spot the Reel viewer. Read in memory, never saved.
What it keepsAn on/off switch and a daily count.
Your messagesNever recorded, copied or sent.
VerifyThe code is public and GitHub builds the APK from it.

Accessibility is a powerful permission. Install Bloom only from this page or its GitHub repo.
